# Виртуальная примерочная (3D-аватар по меркам)

Веб-сервис для магазина одежды: пользователь вводит мерки, получает параметрический 3D-аватар, примеряет вещи каталога в разных размерах и видит карту посадки с рекомендацией размера.

Подробности — в `docs/`. Точка входа для разработки — `docs/PLAN.md` (план с чекбоксами) и `docs/STATUS.md` (текущее состояние).

## Структура

```
pipeline/   Python-скрипты для Blender (генерация тела, одежды, экспорт GLB)
web/        виджет: React + TypeScript + Vite + Three.js (react-three-fiber)
server/     FastAPI + PostgreSQL (появляется на этапе 5)
assets/     исходники (.blend) и готовые GLB (крупные файлы — через Git LFS)
artifacts/  рендеры/скриншоты для визуальной проверки (в .gitignore)
docs/       документация
```

## Быстрый старт

### web (3D-просмотрщик)

```bash
cd web
npm install
npm run dev
```

Откроется dev-сервер Vite (по умолчанию http://localhost:5173).

### pipeline (Blender-скрипты)

Появится на этапе 1. Требует установленного Blender (путь фиксируется в `docs/STATUS.md`).
