# Реестр источников ассетов

Каждый ассет (тело, одежда, причёски, текстуры) фиксируется здесь с указанием
источника и лицензии. Правило проекта: **только CC0** или собственная генерация.
SMPL/SMPL-X запрещены (некоммерческая лицензия).

## Допустимые лицензии

- **CC0 1.0** — можно всё, включая коммерцию, без атрибуции. Предпочтительно.
- Собственная генерация (наши Blender-скрипты) — наша собственность.

## Запрещено

- SMPL / SMPL-X / STAR и производные — некоммерческая лицензия.
- Любые ассеты без явно указанной лицензии.
- CC-BY-NC, CC-BY-ND и прочие c ограничением на коммерцию/модификацию.
