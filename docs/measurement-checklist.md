# Чек-лист обмера изделий для виртуальной примерочной

Цель этого документа — собрать мерки вещей, по которым мы строим 3D-модель и считаем рекомендацию размера. Меряем не тело, а само изделие, разложенное на столе.

## Как мерить (общие правила, прочитать один раз)

- Вещь раскладываем на ровной поверхности, разглаживаем руками, без натяжения. Молнии и пуговицы застёгиваем.
- Меряем сантиметровой лентой по плоскости, то есть ширину разложенной вещи от шва до шва. Это не обхват. Обхват мы потом посчитаем сами, умножив ширину на два.
- Все значения в сантиметрах, с точностью до 0,5 см.
- Каждый размер меряем отдельно, на реальном образце. Если размера нет в наличии, отмечаем это, не пишем на глаз.
- Если ткань тянется, всё равно меряем в спокойном состоянии, без растяжения. Про тянучесть есть отдельный пункт в конце.

Маленькая схема, что значит «ширина по плоскости»: представь футболку, лежащую на столе. Лента идёт от левого бокового шва до правого по прямой. Это и есть ширина по груди. Реальный обхват груди вещи в два раза больше, его считаем мы.

## Что мерить по типам одежды

### Верх (футболки, лонгсливы, худи, свитшоты, топы, рубашки)

- Длина изделия. От высшей точки плеча у горловины вертикально вниз до низа.
- Ширина по груди. Поперёк, на 2-3 см ниже проймы, от шва до шва.
- Ширина по низу. Поперёк по самому краю подола.
- Ширина плеч. По спинке от одного плечевого шва до другого.
- Длина рукава. От плечевого шва до края манжеты. Если плечо спущенное или реглан, меряем от центра горловины сзади до края рукава и помечаем это.
- Ширина рукава вверху. Поперёк рукава в самой широкой части под проймой.
- Ширина манжеты или низа рукава.
- Ширина горловины. Между внутренними краями горловины от шва до шва.

Для худи дополнительно, если не лень: высота капюшона и его ширина в самом широком месте. Это не критично, но делает капюшон в 3D живее.

### Низ (штаны, джоггеры, шорты)

- Обхват пояса. По верхнему краю от края до края, мы удвоим. Обязательно пометить, на резинке пояс или нет.
- Если пояс на резинке, дать два значения. В покое и максимально растянутый.
- Ширина бёдер. Поперёк в самой широкой части от шва до шва.
- Высота посадки. От верхнего края пояса спереди до точки соединения штанин (линия шага).
- Длина по внутреннему шву. От линии шага до низа штанины.
- Длина по боковому шву. От пояса до низа сбоку.
- Ширина штанины внизу.

### Платья и комбинезоны

- Длина изделия. От высшей точки плеча вниз до низа.
- Ширина по груди.
- Ширина по талии. В самом узком месте.
- Ширина по бёдрам.
- Ширина по низу (подолу).
- Ширина плеч.
- Длина рукава, если есть рукав.
- Для комбинезонов добавить высоту посадки и длину по внутреннему шву, как у штанов.

### Юбки

- Обхват пояса. По верхнему краю, плюс пометка про резинку.
- Ширина по бёдрам.
- Длина изделия. От пояса до низа.
- Ширина по низу.

## Что указать про каждую вещь кроме цифр

Эти поля влияют на точность рекомендации не меньше, чем сами мерки.

- Тип кроя. Оверсайз, прямой или приталенный.
- Тянется ли ткань. Нет, немного или сильно. Если в составе есть эластан, лайкра, спандекс, это «тянется».
- Состав ткани. У вас он уже есть в карточках, просто продублировать рядом с мерками.
- На какой размерный ряд рассчитана вещь. Например S/M соответствует обычным каким размерам.
- Особенности, ломающие обычную логику. Сильно укороченный крой у кроп-топа, запах, асимметрия, разрезы. Одна строчка словами.

## Формат сдачи

Удобнее всего одна таблица на товар. Строки — размеры, столбцы — мерки. Пример для худи:

| Размер | Длина изделия | Ширина по груди | Ширина по низу | Ширина плеч | Длина рукава | Ширина рукава вверху | Ширина горловины |
|--------|---------------|------------------|-----------------|--------------|---------------|------------------------|-------------------|
| S/M    |               |                  |                 |              |               |                        |                   |
| M/L    |               |                  |                 |              |               |                        |                   |

Плюс под таблицей строчка про крой, тянучесть и состав.

Подойдёт что угодно, в чём это удобно заполнить. Google-таблица, Excel, даже фото листа с цифрами от руки. Главное, чтобы каждая мерка была подписана и было понятно, какой это размер.
