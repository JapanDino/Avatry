## Этап 1. Параметрическое тело (proof of concept)

Цель: тело MakeHuman с морфами крутится в браузере и меняется слайдерами в реальном времени.

- [x] 1.1. Установить Blender, зафиксировать путь к `blender.exe` в STATUS.md — Blender 5.1.2, Python 3.13.9, bpy headless проверен
- [x] 1.2. Установить аддон MPFB2 + базовые ассеты тела; проверить генерацию тела в headless-режиме — MPFB 2.0.15 поставлен через extensions.blender.org (`blender --online-mode --command extension install mpfb --enable`), совместим с Blender 5.1; `HumanService.create_human()` генерит тело headless (19158 верт., shape keys, рост ~1.69 м). Импорт модуля: `bl_ext.blender_org.mpfb.*`
- [x] 1.3. Скрипт `pipeline/gen_body.py`: генерирует базовое тело с shape keys `height, weight, chest, waist, hips` (нейтраль + дельта-морфы через MPFB макросы и measure-таргеты, запекание). Проверено: все 5 морфов несут дельты. Муж/жен — отдельный пол пока через макрос gender; раздельные GLB по полу вынесены в калибровку (этап 3)
- [x] 1.4. Скрипт `pipeline/export_glb.py`: экспорт GLB с морфами; самопроверка — 5 морф-таргетов (`height, weight, chest, waist, hips` в extras.targetNames), размер 1.305 МБ ≤ 4 МБ
- [x] 1.5. Превью тела для визуальной проверки — `artifacts/review/stage1-clean-neutral.png` (рендер в браузере вместо Blender-рендера, релевантнее для Gate)
- [x] 1.6. `web/`: компонент `<AvatarViewer>` — загрузка GLB, свет, камера, пол; нейтральный матовый материал кожи (`web/src/AvatarViewer.tsx`)
- [x] 1.7. `web/`: панель из 5 слайдеров, привязанных к morph target influences по имени; изменения применяются без перезагрузки модели (`web/src/Sliders.tsx`, `web/src/store.ts`)
- [x] 1.8. Проверка крайних значений: морфы на max/min, фигура не рвётся — `artifacts/review/stage1-morphed.png` (рост+грудь+бёдра max, талия −0.6)
- [x] 1.9. (added) Расширенный набор морфов до 10: + `muscle, shoulders, neck, arm, thigh` (макрос muscle + measure-таргеты). `morphs.py`, `gen_body.py`, web-стор/слайдеры обновлены
- [x] 1.10. (added) Базовый комплект одежды «для приличия»: `pipeline/gen_clothing.py` строит верх + шорты, наследующие все 10 морфов. Экспорт `top.glb`/`shorts.glb`, надеты по умолчанию + переключатель. Одежда **свободная (драпировка)**: слои раздуваются к ширине груди + ease (`_drape`, cinch-параметр), ткань висит от плеч, а не облегает. Проверено на нейтрали и полной фигуре (`artifacts/review/stage1-drape3-*.png`)
- [x] 1.11. (added) Реальная физика ткани (исследование): `pipeline/sim_garment.py` — cloth-симуляция даёт драпировку со складками. Рабочий инструмент, но даёт рваный ворот → для аккуратной одежды заменён на готовые ассеты (1.12). Симуляцию оставляем для будущей «живости» подола/рукавов.
- [x] 1.12. (added) **Аккуратная одежда из готовых CC0-ассетов MakeHuman (MHCLO).** `pipeline/gen_mhclo_garment.py`: MPFB примеряет вещь (`add_mhclo_asset`), морфы тела переносятся в одежду по ближайшей вершине (KD-дерево) — чисто следует за фигурой без протыканий. Футболка `elvs_crude_t-shirt_male` (CC0, пак shirts01) — настоящая топология: рукава, ворот, подол. Проверено на нейтрали и полной фигуре (`artifacts/review/stage1-mhclo-*.png`). Это целевой метод привязки одежды каталога (этап 2).
- [x] 1.13. (added) Проход по качеству рендера: студийное окружение (процедурные Lightformer'ы, без сетевых HDRI), контактные/мягкие тени, ACES-тонмаппинг; футболка сглажена subdivision (`gen_mhclo_garment --subdiv`).
- [x] 1.14. (added) Пост-обработка + фактура ткани: N8AO (ambient occlusion) + лёгкий Bloom + SMAA (`@react-three/postprocessing`); процедурная карта нормалей ткани (плетение) на одежде. Итог — `artifacts/review/stage1-quality-final.png`. Известно: ~180 безвредных WebGL-warning (`glBlitFramebuffer` от N8AO/depth), консольный шум, на картинку не влияет — пересмотреть позже.
- [x] 1.15. (added) Физика ткани для футболки (выбран путь «Blender-сим → морфы»): `pipeline/sim_morph_garment.py` — старт из MHCLO+припуск, нейтраль из cloth-симуляции (свободная драпировка), морфы линейным переносом по ближайшей вершине (стабильно на комбинациях). Шорты — уменьшил припуск. Урок: per-morph симуляции нельзя складывать (рвут меш) — см. DECISIONS. `artifacts/review/stage1-physim-*.png`
- [x] 1.16. (added) Два пола: мужское и женское тело (`gen_body.py --gender`, макрос пола MakeHuman + грудь/пропорции), свои GLB. Своя одежда: жен. футболка `joepal_crude_t-shirt_female` (CC0) + муж. `elvs_crude_t-shirt_male`, шорты на каждый пол. Просмотрщик грузит модели по полу.
- [x] 1.17. (added, заход в этап 3) Форма мерок вместо ползунков: пол + рост/вес/обхваты груди/талии/бёдер → морфы считаются по калибровке (`pipeline/calibrate.py` → `web/public/calibration.json`, обхваты = периметр выпуклой оболочки среза торса). Ползунки морфов убраны в свёрнутую «Тонкую настройку». `artifacts/review/stage3-*.png`
- [x] **Gate 1 (пользователь):** фигура и базовая одежда выглядят адекватно — **закрыт пользователем 2026-06-12** (одобрены тело, физика ткани, 2 пола, ввод по меркам).
